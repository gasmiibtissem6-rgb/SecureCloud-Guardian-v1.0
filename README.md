
# 🛡️ SecureCloud Guardian v1.0

Plateforme de sécurité cloud automatisée combinant cybersécurité et DevSecOps.

## Fonctionnalités
- 🔍 Détection de secrets exposés (TruffleHog)
- ⚡ API REST (FastAPI)
- 🎨 Dashboard HTML temps réel
- 📊 Rapports JSON automatiques

## Installation
```bash
pip install fastapi uvicorn
python3 -m uvicorn api.main:app --port 8000
```

## Usage
Ouvrir `dashboard/index.html` dans le navigateur
